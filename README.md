# שומר שיחות (CallGuard)

אפליקציית אנדרואיד לסינון שיחות מאנשי קשר שבוחרים. לכל איש קשר בוחרים אחת משלוש התנהגויות:

| מצב | מה קורה אצלך | מה שומע המתקשר |
|---|---|---|
| **חסימה** | שום דבר. מתקבלת התראה "שיחה נחסמה", והשיחה נרשמת ביומן | השיחה נדחית (תפוס או תא קולי) |
| **התעלמות** | הטלפון שקט. מופיעה שיחה שלא נענתה | צלצול רגיל, עד שהרשת מעבירה לתא קולי |
| **ניתוק אוטומטי** | הטלפון שקט (או מצלצל, לבחירתך) ומנתק אחרי N צלצולים | צלצול, ואחריו ניתוק |

### תזמון

אפשר להגביל כל כלל לשעות ולימים מסוימים, למשל "מ-16:00 עד 00:00, בימים א׳ עד ה׳". מחוץ לחלון הזמן השיחות מאותו איש קשר מגיעות כרגיל. חלון שמסתיים לפני שהוא מתחיל (למשל 22:00 עד 07:00) עובר את חצות, ונחשב כשייך ליום שבו הוא התחיל.

## דרישות

- Android 10 ומעלה
- Android Studio (גרסה עדכנית) ו-JDK 17

## בנייה והתקנה

1. פותחים את התיקייה הזאת ב-Android Studio (File → Open). Android Studio מוריד את Gradle ואת התלויות בעצמו.
2. בטלפון מפעילים אפשרויות מפתחים ו-USB debugging, ומחברים את הטלפון למחשב.
3. לוחצים על Run ▶.

> שם התיקייה כתוב בעברית. הוספתי את `android.overridePathCheck=true` כדי שהבנייה תעבוד, אבל אם מופיעות שגיאות מוזרות בבנייה, כדאי להעתיק את הפרויקט לנתיב באנגלית בלבד, למשל `C:\Projects\CallGuard`.

## הפעלה ראשונה

במסך הראשי מופיע כרטיס "הגדרה ראשונית". צריך לאשר בו:

1. **אפליקציית סינון שיחות:** חובה. בלי זה Android לא מעביר שיחות לאפליקציה.
2. **אנשי קשר:** חובה. Android מעביר לאפליקציית סינון שיחות מאנשי קשר שמורים רק אם יש לה הרשאה לאנשי הקשר.
3. **ניהול שיחות:** רשות. נדרש רק לניתוק אוטומטי.
4. **התראות:** רשות. נדרש להתראה על שיחות שנחסמו.

## מגבלות ידועות

- **ספירת צלצולים היא הערכה.** הטלפון לא יודע כמה צלצולים המתקשר שמע, ולכן צלצול אחד מחושב כ-5 שניות (`PhoneNumbers.SECONDS_PER_RING`).
- **במצב התעלמות מסך השיחה עדיין מופיע.** Android משתיק את הצלצול, אבל אפליקציית הטלפון של המכשיר עדיין מציגה את השיחה הנכנסת. כדי להסתיר גם את המסך האפליקציה צריכה להיות אפליקציית הטלפון הראשית, וזה שלב עתידי.
- **ברכב עם בלוטוס** רק מצב חסימה מונע מענה אוטומטי. במצבי התעלמות וניתוק הרכב עדיין רואה את השיחה.
- **ניתוק אוטומטי** משתמש ב-`TelecomManager.endCall()`, שמסומן deprecated אבל עדיין נתמך באפליקציות עם הרשאת `ANSWER_PHONE_CALLS`. לפני הניתוק האפליקציה בודקת שהשיחה עדיין מצלצלת, כך שהיא לא מנתקת שיחה שכבר נענתה.

## מבנה הקוד

```
app/src/main/java/com/eliya/callguard/
├── CallGuardApp.kt            Application: מאתחל את המאגר וערוצי ההתראות
├── data/
│   ├── Models.kt              Rule, CallEvent, GuardState, RuleMode
│   ├── GuardRepository.kt     מצב בזיכרון ושמירה ל-JSON
│   ├── PhoneNumbers.kt        השוואה ועיצוב של מספרים (+972 / 05x)
│   └── ContactsSource.kt      קריאת אנשי קשר
├── screening/
│   ├── ScreeningService.kt    CallScreeningService: ההחלטה על כל שיחה
│   ├── HangUpService.kt       טיימר ניתוק (foreground service קצר)
│   ├── Notifications.kt       ערוצים והתראות
│   └── SetupStatus.kt         מצב ההרשאות והתפקיד
└── ui/
    ├── MainActivity.kt, AppRoot.kt, MainViewModel.kt
    ├── theme/Theme.kt         פלטת צבעים, טיפוגרפיה וצורות
    ├── components/            אווטאר, תגית מצב, מצב ריק
    └── screens/               כללים, יומן, בחירת איש קשר, עריכת כלל
```
